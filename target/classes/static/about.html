CAMPUS CONNECT 2030

Campus Connect is a comprehensive futuristic university web application built to simulate an orbital academic station in the year 2030. The system demonstrates enterprise Java Spring Boot backend engineering, transactional persistence, Spring Security cryptography, and immersive Three.js spatial web design.

🌱

Spring Boot & Java 21

Built with Java 21 LTS and Spring Boot 3.3.4, implementing Spring Web MVC, Spring Data JPA, Hibernate, Bean Validation, and RESTful JSON controllers.

🛡️

Spring Security & BCrypt

Protected by Spring Security filter chains with BCrypt password hashing. Passwords are never stored in plain text and hashes are strictly excluded from client projections.

🐬

MySQL & JPA Persistence

Structured relational database schema with unique constraints, foreign keys, indexes, and transactional isolation preventing overbooking or duplicate registrations.
